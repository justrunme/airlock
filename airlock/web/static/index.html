Airlock

An LLM agent proposes code. A static policy decides. Allowed code runs in a throwaway container with no network. Every decision is written to an Ed25519-signed, hash-chained receipt you can check in this page.

SRE log triage

The agent gets /work/input/app.log (120 lines) and is asked to count errors per component and write a short report. The model is Qwen on Vultr Serverless Inference. A run takes 20–90 seconds because the model reasons before answering.

B. Replay a compromised agent

  
The proposals in this run are scripted. In my testing the
  live model refused the injected line, so the live run never shows the gate stopping anything.
  This replay plays the actions an agent that obeyed the line would propose. Only the
  proposals are fixed. The policy verdicts, the sandbox run, the verifier and every signed receipt
  are real and come from the same code path as the live run. Each receipt says
  "context": {"mode": "replay_compromised", "planner": "scripted"}.

Attack arena

  
Submit Python or bash. It goes through the same policy and sandbox as the agent's code:
  no network, read-only root, no capabilities, no secrets, 10 s, 128 MB, 32 pids.
  Benign code runs; anything the policy does not understand is denied.

  
The counter below is global: it adds up every submission from every visitor to this server, not just yours.

Verify a receipt in your browser

  
Verification runs here, with WebCrypto Ed25519 and SHA-256 and an RFC 8785 canonicaliser
  in verify.js (no dependencies). Nothing is sent to the server.
  Steps: strict JSON (duplicate keys rejected) → schema → SHA-256 of the canonical body
  → Ed25519 signature.

Known limitations

  

    
LimitationWhat it means

    
      
Containers share the host kernelUnder runc a kernel bug is a host escape. This deployment runs gVisor (runsc), which puts a user-space kernel in between and shrinks that surface. It does not remove it.

      
The static policy is incompleteIt is an allow-list parser for a subset of Python and bash. Unknown constructs are denied, but a bypass in what it does allow is possible. The sandbox is the second line.

      
Signatures cover the record, not the hostA valid signature proves the receipt came from the holder of this key and was not edited. It does not prove the host was honest or uncompromised when it wrote it.

      
No egress allow-listThe only network mode is none. Tasks that need the network cannot run here.

      
The control process can reach the Docker socketThe API service runs as an unprivileged user in the docker group, which is root-equivalent on this VM. The socket is never mounted into a sandbox or exposed over the network.

      
Receipts are kept, not prunedDeleting one breaks the hash chain. Old work dirs and containers are pruned by a timer.
